## Three recommended design moves

1. Website batch first, cheapest to dearest, because five items edit the same three files: strip internal narrative from built pages, fail-closed dev CORS, build-generated landing figures, one build-rendered header/footer/contact partial from footer-manifest.json, then the About/FAQ + Status archive + Press renovation and the pre-cohort Stats showcase.
2. Visual system before engagement: design-token sweep, SVG icon sprite and procedural team crests land first so the shareable moment cards, the First Season Contract strip and the Desk regroup inherit them instead of being restyled twice.
3. Engine and intelligence last, in dependency order: causal rival personas (trade seam), then the deterministic Front Office Advisor on the Co-GM packet inside the new Desk, then the Worker-hosted local runtime, which changes the transport every earlier item was tested against and so ships with its own Playwright responsiveness spec.
