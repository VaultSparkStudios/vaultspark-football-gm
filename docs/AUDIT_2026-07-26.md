## Three recommended design moves

1. Make every asynchronous browser authority epoch use the exact franchise identity already emitted by the runtime.
2. Treat Opening Contract, Return Digest, and trade-block memory as franchise-scoped state rather than browser-global state.
3. Turn the Return Digest chapter target into one exact continuation action and publish a falsifiable game-loop contract.
