Add correlated write acknowledgments, asynchronous durable mutations and a flush barrier; return persistence failure through the existing API error surface, terminate failed transports and ignore all late writes.
3. Request success currently resolves before transaction completion. Wait for committed transactions, reject aborted and blocked operations with bounded failure, preserve legacy bytes on failed migration, and keep existing IndexedDB saves readable after write degradation.
