Privacy

Browser-First Play

Franchise Architect: Football runs in your browser and saves your leagues there. Your leagues, settings and challenge data stay in your browser unless you export or share them yourself.

Site Measurement

The website measures page views using Cloudflare Web Analytics. It sets no cookies, builds no cross-site profile, and never receives a name, an email address, a save file, or anything typed into the game. It reports only which page was loaded and how quickly it rendered.

This is separate from Community Stats below. Site measurement covers the website; Community Stats covers in-game choices and is off until you turn it on.

Optional Community Stats

Community Stats is off until you choose to take part. When it is on, after each successful game action your browser may send a short, fixed set of categories and numbers, such as league settings, weeks completed, tactics, transactions, draft positions and results.

Community Stats never receives your saves, names, email, free text, passwords or tokens, player identities, hidden ratings, or story history. A random browser identifier is converted into an anonymous code by the service. Internet addresses are used only briefly, in memory, to limit abuse, and are never stored. Individual records are deleted after 30 days. A published figure only appears once at least five participating browsers are counted in it. Turning participation off asks the service to delete the records tied to your browser's identifier.

Published figures describe the browsers that chose to take part, not all players. The methodology explains how to read them.

Feedback

The in-game feedback button prepares a public GitHub issue with basic, public-safe game context. It does not attach personal account data or your save.

Optional Cloud Save Credentials

If you choose GitHub Gist sync, the GitHub token you supply is kept in memory and in storage that lasts only for the current browser tab. Franchise Architect removes any older stored copies, never includes the token in save exports, and sends it only to GitHub's API to perform the sync you asked for. An optional save passphrase is used on your device to create an authentication key; the passphrase is never stored or sent. Authentication detects unauthorized changes but does not encrypt the save stored by GitHub.
