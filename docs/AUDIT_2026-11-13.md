## Three recommended design moves

1. Admit finite numeric values and intentional numeric strings without coercing absent/boolean values. Filter malformed optional rows while preserving bounded valid data and disclosure. Reuse action-error reporting around copy/download import and build, retain clipboard fallback, retry and download cleanup.
2. Reuse the three existing viewport profiles as independent bounded jobs with distinct output paths/artifacts. Aggregate exact required-name coverage, themes, source revision and artifact digest before publication. Reject missing/duplicate/mismatched/invalid profiles; retain partial failure diagnostics and per-viewport timings. Preserve every capture and assertion and the eight-minute per-job bound.
3. Use existing projected suspension, reserve, practice, inactive and medical facts before healthy prose. Preserve concurrent restrictions, explain current availability without inventing eligibility, and handle recovered or malformed optional injury data.
