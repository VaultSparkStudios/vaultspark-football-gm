# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in **Franchise Architect: Football**, please report it
privately. **Do not open a public issue for security problems.**

- **Email:** founder@vaultsparkstudios.com (subject: `SECURITY — Franchise Architect: Football`)
- **GitHub private vulnerability reporting:** if enabled on this repository
  (Security → "Report a vulnerability"), prefer that channel.

Please include what you found, steps to reproduce it, the affected version or commit,
and any suggested remediation.

## Scope

- In scope: this repository's code, configuration, and deployed surfaces.
- Out of scope: social engineering and physical attacks. Report vulnerabilities
  in third-party dependencies to their maintainers.

## Disclosure

We follow coordinated disclosure: we'll work with you on a fix and a reasonable
disclosure timeline, and credit you if you wish.
