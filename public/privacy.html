Privacy

Browser-First Beta

Franchise Architect: Football is designed to run in the browser with local save data. Local leagues, settings, and optional challenge data remain in the player's browser unless the player explicitly exports or shares them.

Optional Community Stats

Community Stats is off until the player chooses to participate. After a successful game command, the browser may share an allowlisted receipt containing categories and bounded numbers such as league settings, weeks completed, tactics, transactions, draft positions, and outcomes.

Community Stats never receives full saves, names, email, free text, credentials, raw player identifiers, hidden ratings, or narrative history. A random browser identifier is one-way hashed by the service; internet protocol addresses are used only in an in-memory rate limiter and are never stored. Raw receipts expire after 30 days, public behavioral cells require at least five participating browsers, and stopping participation requests deletion of receipts tied to the browser identifier.

The public denominator is participating anonymous browsers, not all players or all humans. See the full methodology.

Feedback

The in-game feedback path opens a public GitHub issue draft with public-safe game context. It does not attach personal account data or full save payloads.

Optional Cloud Save Credentials

If a player chooses GitHub Gist sync, the user-supplied GitHub token is kept in memory and tab-scoped session storage only. Franchise Architect removes legacy persistent token copies, never includes the token in save exports, and sends it only to the GitHub application programming interface for the requested sync action.
