## Three recommended design moves

1. Guard storage access and retain the explicit mobile/full-view preference in this tab when reads or writes fail. Preserve stored preferences and viewport defaults. Verify getter/read/quota failures, both switch directions and actual mobile navigation in both themes.
2. Validate persisted prediction maps, entries, statistics and receipts before use. Discard malformed data without invented grades. Keep league/year/week isolation, engine input immutability and once-only grading. Prove dashboard hydration with corrupt optional storage and normal prediction submission/settlement.
3. Retain validated earned trophy records in tab memory when persistence fails. Deduplicate repeated events, keep browser-wide cross-franchise trophy semantics, restore durable data without losing tab awards, and explain temporary persistence truthfully in Trophy Case. Verify repeated events, malformed records, quota/read/getter failures and actual desktop/mobile renders in both themes.
