## Three recommended design moves

1. Guard tutorial reads, writes and removals independently. Keep authoritative completion receipts unchanged and make persistence best effort. Verify skip and applied-receipt dismissal with quota and denied storage failures in both themes and desktop/mobile.
2. Use one safe storage accessor for the six reproduced modules. Preserve injected storage and franchise keys. Return false when no return boundary can be written. Test denied getters, missing storage, normal storage and cross-franchise isolation.
3. Make optional feedback cadence reads and writes safe. Require an actual receipt writer for successful saving. Catch save failure in the contextual prompt, retain the draft and show an accessible retry message; never invoke onSaved or mark completed after a failed save. Test denied reads, quota failure and a successful retry in both themes and desktop/mobile.
